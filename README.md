# Kinly — how it works

A single-page explainer for [Kinly](https://github.com/lemon-sandwich/Kinly), family-controlled
call protection for an elderly person's existing phone number.

Published at **https://lemon-sandwich.github.io/kinly-site/**

One self-contained `index.html` — no build step, no dependencies, no external requests.
Edit it and push to `main`; GitHub Pages redeploys automatically.
